# Finanzas Personales - Demo Cliente

Portal de demostración del sistema de finanzas personales. 

## Descripción
Esta es una demo interactiva con datos embebidos (julio-septiembre 2026). No está conectada a ninguna base de datos real.

## Uso
Simplemente abra `index.html` en su navegador. Los movimientos nuevos se guardan en el `localStorage` de su navegador.

## Información Técnica
- Stack: HTML5, CSS3, Vanilla JS, Chart.js.
- Persistencia: `localStorage`.
